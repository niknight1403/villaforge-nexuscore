# NexusCore

Zentrales Orchestrierungs-Framework für autonome Agenten-Villen.

## Struktur
- cmd/nexuscore: Einstiegspunkt
- internal/: Kernlogik (API, Billing, Scheduler)
- pkg/: Gemeinsame Bibliotheken
- web/: Dashboard (React 19)
- docker/: Container-Konfigurationen
