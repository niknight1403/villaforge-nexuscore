# NexusCore

Zentrales Orchestrierungs-Framework für autonome Agenten-Villen.

## Tech-Stack
- Core: Go 1.23
- Queue: Redis
- Database: PostgreSQL
- Frontend: React 19

## Status
Projektinitialisierung abgeschlossen. API-Gateway mit JWT-Unterstützung in Entwicklung.
